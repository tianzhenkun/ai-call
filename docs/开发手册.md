## 开发流程

开发一个新模块的推荐顺序：

```
Model (model.py) → Schema (schema.py) → CRUD (crud.py) → Service (service.py) → Controller (controller.py)
```

## 分层架构

```
Controller 层 → HTTP 请求处理、权限控制
     ↓
Service 层 → 业务逻辑处理、数据转换
     ↓
CRUD 层 → 数据库操作、权限过滤
     ↓
Model 层 → 数据库表定义、ORM 映射
```

## 各层开发规范

### 1. Model 层 (model.py)

**职责**：定义数据库表结构（DDL）

> **重要**：Model 仅用于数据库表定义和写操作，**所有查询操作必须使用原生 SQL**。

```python
from datetime import datetime
from sqlalchemy import String, Integer, DateTime, Text
from sqlalchemy.orm import Mapped, mapped_column
from app.core.base_model import MappedBase


class ArticleModel(MappedBase):
    """文章模型"""
  
    __tablename__: str = "sys_article"
    __table_args__: dict[str, str] = {"comment": "文章信息表"}
  
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True, comment="主键ID")
    uuid: Mapped[str] = mapped_column(String(64), default=lambda: str(__import__("uuid").uuid4()), nullable=False, unique=True, comment="UUID")
    status: Mapped[str] = mapped_column(String(10), default="0", comment="状态(0:正常 1:停用)")
    created_time: Mapped[datetime] = mapped_column(DateTime, default=datetime.now, comment="创建时间")
    updated_time: Mapped[datetime] = mapped_column(DateTime, default=datetime.now, onupdate=datetime.now, comment="更新时间")
    title: Mapped[str] = mapped_column(String(100), nullable=False, comment="文章标题")
    content: Mapped[str | None] = mapped_column(Text, nullable=True, comment="文章内容")
    author: Mapped[str] = mapped_column(String(50), nullable=False, comment="作者")
    category_id: Mapped[int | None] = mapped_column(Integer, nullable=True, comment="分类ID")
```

**注意事项**：

- 使用 `Mapped[type]` 类型注解和 `mapped_column()` 定义字段
- 添加 `comment` 参数描述字段用途
- 字符串字段必须指定长度

### 2. Schema 层 (schema.py)

**职责**：定义数据验证和序列化模型

| 模型类型         | 用途         |
| ---------------- | ------------ |
| `CreateSchema` | 创建请求参数 |
| `UpdateSchema` | 更新请求参数 |
| `OutSchema`    | 响应输出模型 |
| `QueryParam`   | 查询参数模型 |

```python
from fastapi import Query
from pydantic import BaseModel, ConfigDict, Field
from app.core.base_schema import BaseSchema, UserBySchema


class ArticleCreateSchema(BaseModel):
    """文章创建模型"""
    title: str = Field(..., description="文章标题", max_length=100)
    content: str | None = Field(default=None, description="文章内容")
    author: str = Field(..., description="作者", max_length=50)
    category_id: int | None = Field(default=None, description="分类ID")
    status: str = Field(default="0", description="状态")


class ArticleOutSchema(BaseSchema, UserBySchema):
    """文章输出模型"""
    model_config = ConfigDict(from_attributes=True)
    title: str = Field(..., description="文章标题")
    content: str | None = Field(default=None, description="文章内容")
    author: str = Field(..., description="作者")
    category_id: int | None = Field(default=None, description="分类ID")


class ArticleQueryParam(BaseModel):
    """文章查询参数"""
    model_config = ConfigDict(from_attributes=True)
    title: str | None = Field(default=None, description="文章标题")
    author: str | None = Field(default=None, description="作者")
    status: str | None = Field(default=None, description="状态")
  
    def __init__(self, **data):
        super().__init__(**data)
        if self.title:
            self.title = ("like", self.title)  # 模糊查询
        if self.status:
            self.status = ("eq", self.status)  # 精确查询
```

**查询条件格式**：

| 格式                          | 说明     | 示例                                          |
| ----------------------------- | -------- | --------------------------------------------- |
| `("eq", value)`             | 等于     | `("eq", "0")`                               |
| `("like", value)`           | 模糊查询 | `("like", "关键词")`                        |
| `("in", [values])`          | 包含     | `("in", [1, 2, 3])`                         |
| `("between", (start, end))` | 范围     | `("between", ("2025-01-01", "2025-12-31"))` |
| `("gt", value)`             | 大于     | `("gt", 100)`                               |
| `("lt", value)`             | 小于     | `("lt", 100)`                               |

### 3. CRUD 层 (crud.py)

**职责**：封装数据库操作

> **重要**：**所有查询操作必须使用原生 SQL 方法**，ORM 方法仅用于写操作（create/update/delete）。

| 操作类型                | 推荐方法          | 说明                       |
| ----------------------- | ----------------- | -------------------------- |
| **创建**          | `create()`      | ORM 自动填充审计字段       |
| **更新**          | `update()`      | ORM 自动更新审计字段       |
| **删除**          | `delete()`      | ORM 方便                   |
| **列表查询**      | `raw_dicts()`   | **必须使用原生 SQL** |
| **单行查询**      | `raw_one()`     | **必须使用原生 SQL** |
| **分页查询**      | `raw_page()`    | **必须使用原生 SQL** |
| **统计查询**      | `raw_scalar()`  | **必须使用原生 SQL** |
| **批量更新/删除** | `raw_execute()` | **必须使用原生 SQL** |

```python
from app.api.v1.system.auth.schema import AuthSchema
from app.core.base_crud import CRUDBase
from .model import ArticleModel
from .schema import ArticleCreateSchema, ArticleUpdateSchema


class ArticleCRUD(CRUDBase[ArticleModel, ArticleCreateSchema, ArticleUpdateSchema]):
    """文章数据层"""
  
    def __init__(self, auth: AuthSchema) -> None:
        super().__init__(model=ArticleModel, auth=auth)
  
    async def create_article(self, data: ArticleCreateSchema) -> ArticleModel:
        """创建文章"""
        return await self.create(data=data)
  
    async def update_article(self, id: int, data: ArticleUpdateSchema) -> ArticleModel:
        """更新文章"""
        return await self.update(id=id, data=data)
  
    async def delete_articles(self, ids: list[int]) -> None:
        """删除文章"""
        await self.delete(ids=ids)
  
    async def get_by_id(self, article_id: int) -> dict | None:
        """根据ID获取文章"""
        return await self.raw_one("SELECT * FROM sys_article WHERE id = :id", {"id": article_id})
  
    async def get_list(self, status: str = "0") -> list[dict]:
        """获取文章列表"""
        return await self.raw_dicts("SELECT * FROM sys_article WHERE status = :status ORDER BY created_time DESC", {"status": status})
  
    async def get_page(self, page_num: int, page_size: int, status: str = "0") -> dict:
        """分页查询文章"""
        return await self.raw_page(
            "SELECT * FROM sys_article WHERE status = :status ORDER BY created_time DESC",
            {"status": status}, page_num=page_num, page_size=page_size
        )
```

**安全注意事项**：

```python
# ✅ 正确：使用命名参数（防止 SQL 注入）
await crud.raw_dicts("SELECT * FROM sys_article WHERE title = :title", {"title": user_input})

# ❌ 错误：字符串拼接（存在 SQL 注入风险）
await crud.raw_dicts(f"SELECT * FROM sys_article WHERE title = '{user_input}'")
```

### 4. Service 层 (service.py)

**职责**：实现业务逻辑

```python
from app.api.v1.system.auth.schema import AuthSchema
from app.core.exceptions import CustomException
from .crud import ArticleCRUD
from .schema import ArticleCreateSchema, ArticleUpdateSchema, ArticleOutSchema


class ArticleService:
    """文章服务层"""
  
    @classmethod
    async def create_service(cls, auth: AuthSchema, data: ArticleCreateSchema) -> dict:
        """创建文章"""
        existing = await ArticleCRUD(auth).get_by_title(title=data.title)
        if existing:
            raise CustomException(msg="文章标题已存在")
        article = await ArticleCRUD(auth).create(data=data)
        return ArticleOutSchema.model_validate(article).model_dump()
  
    @classmethod
    async def get_detail_service(cls, auth: AuthSchema, id: int) -> dict:
        """获取文章详情"""
        article = await ArticleCRUD(auth).get_by_id(article_id=id)
        if not article:
            raise CustomException(msg="文章不存在")
        return ArticleOutSchema.model_validate(article).model_dump(by_alias=True)
  
    @classmethod
    async def get_page_service(cls, auth: AuthSchema, page_num: int, page_size: int, status: str | None = None) -> dict:
        """获取分页数据"""
        result = await ArticleCRUD(auth).get_page(page_num=page_num, page_size=page_size, status=status)
        rows = [ArticleOutSchema.model_validate(r).model_dump(by_alias=True) for r in result.get("rows", [])]
        return {"total": result.get("total", 0), "rows": rows}
```

### 5. Controller 层 (controller.py)

**职责**：定义 HTTP 接口

```python
from typing import Annotated
from fastapi import APIRouter, Depends, Path
from fastapi.responses import JSONResponse
from app.api.v1.system.auth.schema import AuthSchema
from app.common.response import ResponseSchema, SuccessResponse, TableResponse
from app.core.base_params import PaginationQueryParam
from app.core.dependencies import get_current_user
from app.core.router_class import OperationLogRoute
from .schema import ArticleCreateSchema, ArticleUpdateSchema, ArticleOutSchema, ArticleQueryParam
from .service import ArticleService


ArticleRouter = APIRouter(route_class=OperationLogRoute, prefix="/article", tags=["文章管理"])


@ArticleRouter.post("/create", summary="创建文章", response_model=ResponseSchema[ArticleOutSchema])
async def create_controller(data: ArticleCreateSchema, auth: Annotated[AuthSchema, Depends(get_current_user)]) -> JSONResponse:
    result = await ArticleService.create_service(auth=auth, data=data)
    return SuccessResponse(data=result, msg="创建成功")


@ArticleRouter.get("/page", summary="分页查询文章")
async def get_page_controller(
    page: Annotated[PaginationQueryParam, Depends()],
    search: Annotated[ArticleQueryParam, Depends()],
    auth: Annotated[AuthSchema, Depends(get_current_user)],
) -> JSONResponse:
    result = await ArticleService.get_page_service(auth=auth, page_num=page.page_num, page_size=page.page_size)
    return TableResponse(rows=result.get("rows", []), total=result.get("total", 0), msg="查询成功")
```

### API 返回格式

> **重要**：项目全局使用\*\*驼峰命名（camelCase）\*\*返回数据给前端。

| 层级        | 命名格式              | 示例                          |
| ----------- | --------------------- | ----------------------------- |
| 数据库字段  | 下划线（snake\_case） | `user_id`, `created_time` |
| Python 代码 | 下划线（snake\_case） | `user_id`, `created_time` |
| API 返回    | 驼峰（camelCase）     | `userId`, `createdTime`   |

```python
from pydantic import BaseModel, ConfigDict
from pydantic.alias_generators import to_camel

class UserOutSchema(BaseModel):
    model_config = ConfigDict(from_attributes=True, alias_generator=to_camel, populate_by_name=True)
    user_id: int         # 输出为 userId
    user_name: str       # 输出为 userName
    created_time: datetime  # 输出为 createdTime
```

**注意事项**：

1. 所有 Schema 继承 `BaseSchema` 或 `CommonSchema` 已自动配置驼峰转换
2. 使用 `model_dump(by_alias=True)` 输出驼峰格式

## 权限控制

```python
from app.core.dependencies import AuthPermission

# 基本权限验证（仅验证登录状态）
@router.get("/list")
async def get_list(auth: AuthSchema = Depends(AuthPermission())):
    return {"message": "访问成功"}

# 带数据权限的验证
@router.get("/detail/{id}")
async def get_detail(id: int, auth: AuthSchema = Depends(AuthPermission(check_data_scope=True))):
    return {"id": id, "user_id": auth.user.id}
```

| 场景                 | 验证逻辑             |
| -------------------- | -------------------- |
| **超级管理员** | 直接通过所有权限验证 |
| **未启用 JWT** | 默认放行所有请求     |
| **已登录用户** | 基本权限验证通过     |
| **未登录用户** | 返回 401 未授权错误  |

## 用户认证与上下文（未开启JWT时获取不到，本地开发不需要开启）

`get_current_user` 是 FastAPI 的依赖注入函数，用于：

1. **解析 JWT Token** - 从请求头 `Authorization: Bearer <token>` 中提取并验证 Token
2. **获取用户信息** - 解析 Token 中的用户 ID、用户名、租户 ID、部门 ID 等
3. **设置请求上下文** - 将用户信息存入 `request.scope`
4. **返回认证对象** - 返回 `AuthSchema` 对象

```python
from fastapi import Depends, Request
from app.core.dependencies import get_current_user
from app.api.v1.system.auth.schema import AuthSchema

@router.get("/profile")
async def get_profile(auth: AuthSchema = Depends(get_current_user)):
    return {"user_id": auth.user.id, "username": auth.user.username}

@router.get("/info")
async def get_info(request: Request):
    return {
        "user_id": request.scope.get("user_id"),
        "username": request.scope.get("username"),
        "tenant_id": request.scope.get("tenant_id"),
        "dept_id": request.scope.get("dept_id")
    }
```

## OSS 对象存储使用

> 这里的"OSS"是指**对象存储服务**，对应数据库表 `sys_oss`，用于管理上传的文件信息。

### 字段说明

| 字段              | 类型   | 说明                           |
| ----------------- | ------ | ------------------------------ |
| `oss_id`        | bigint | 对象存储主键（唯一标识）       |
| `file_name`     | string | 文件名（存储在OSS中的名称）    |
| `original_name` | string | 原名（用户上传时的原始文件名） |
| `file_suffix`   | string | 文件后缀名（如 .jpg, .pdf）    |
| `url`           | string | URL地址（文件的访问地址）      |
| `service`       | string | 服务商（如 minio, oss）        |

### 常用场景

#### 1. 根据 oss\_id 获取文件 URL

**用途**：已知文件的 `oss_id`，需要获取文件的访问地址（`url`）进行后续处理。

```python
from app.api.v1.system.oss.service import OssService

# 根据 oss_id 获取 URL 信息
result = await OssService.get_url_by_oss_id_service(auth=auth, oss_id=123)
# 返回: {"ossId": 123, "url": "http://minio.xxx.com/bucket/xxx.jpg", "originalName": "头像.jpg", "fileSuffix": ".jpg"}

# 使用 url 进行后续处理（如下载、替换变量、盖章等）
file_url = result["url"]
```

#### 2. 根据 oss\_id 获取文件完整信息

**用途**：需要获取文件的完整信息，包括上传人、创建时间等。

```python
from app.api.v1.system.oss.service import OssService

# 根据 oss_id 获取完整信息
result = await OssService.get_by_oss_id_service(auth=auth, oss_id=123)
# 返回包含所有字段的完整对象信息
```

#### 3. 批量获取文件 URL

**用途**：列表中包含多个 `oss_id`，需要批量获取对应的文件信息。

```python
from app.api.v1.system.oss.service import OssService

# 批量获取 URL 信息
result = await OssService.get_url_list_by_oss_ids_service(auth=auth, oss_ids=[1, 2, 3])
# 返回: [{"ossId": 1, "url": "...", "originalName": "文件1.pdf", ...}, ...]
```

## 原生 SQL 查询

CRUDBase 提供 5 个原生 SQL 异步方法：

| 方法              | 返回类型        | 用途                        |
| ----------------- | --------------- | --------------------------- |
| `raw_dicts()`   | `list[dict]`  | 列表查询                    |
| `raw_one()`     | `dict \| None` | 单行查询                    |
| `raw_scalar()`  | `Any`         | 单值查询（COUNT/SUM/MAX等） |
| `raw_page()`    | `dict`        | 分页查询                    |
| `raw_execute()` | `Result`      | 执行更新/删除 SQL           |

**优势**：性能高 10-30%、灵活性高、支持复杂查询、内存占用小。

```python
# 列表查询
users = await crud.raw_dicts("SELECT user_id, user_name FROM sys_user WHERE status = :status", {"status": "0"})

# 单行查询
user = await crud.raw_one("SELECT * FROM sys_user WHERE user_id = :id", {"id": 1})

# 聚合查询
count = await crud.raw_scalar("SELECT COUNT(*) FROM sys_user WHERE status = :status", {"status": "0"})

# 分页查询
result = await crud.raw_page("SELECT * FROM sys_user WHERE status = :status ORDER BY user_id", {"status": "0"}, page_num=1, page_size=10)

# 批量更新
result = await crud.raw_execute("UPDATE sys_user SET status = :status WHERE dept_id = :dept_id", {"status": "1", "dept_id": 10})
```

## 操作日志

在创建路由时，设置 `route_class=OperationLogRoute` 即可启用操作日志：

```python
from app.core.router_class import OperationLogRoute

ArticleRouter = APIRouter(route_class=OperationLogRoute, prefix="/article", tags=["文章管理"])
```

| 作用               | 说明                             |
| ------------------ | -------------------------------- |
| **审计追踪** | 记录用户操作行为，便于后续审计   |
| **性能监控** | 记录接口响应时间，发现性能瓶颈   |
| **问题排查** | 出现问题时，通过日志快速定位原因 |
