## 修复行为及边界

确定的缺口是输出校验只检查 JSON、变量和链接等结构，不检查正文语言；英文要求已在历史请求中送达模型。此次明确 instruction 优先于往来素材，并在所有生成、修改及中文审阅入口共享语言校验。

1. 识别当前编辑要求中明确的中文或英文单语要求；中文审阅固定生成中文。双语、歧义和其他语种不擅自推断，也不限制其正常生成。
2. 正文按 HTML 段落检查。英文正文排除资料中已知的客户姓名、公司名、职务、模板变量及地址后，仍有汉字即触发纠正；中文正文允许 GEO、AI 等术语，并检查是否留有英文段落。
3. 标题、列表和签名标语也遵从正文目标语言，回复主题保留原线程与 REACH 编号。
4. 不符时复用既有的一次自动纠正，第二次仍错返回 `EMAIL_AI_LANGUAGE_MISMATCH`，保留原草稿。每次调用的实际 usage、response ID、目标语言和错误原因继续保存，不额外调用检查模型。

此检查覆盖本次中英文问题，不是任意语种识别或邮件业务事实校验；无法从资料确认的专有名称仍可能需要人工审阅。
